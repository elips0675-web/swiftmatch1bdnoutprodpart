# Сводная оценка доработок (qwen + дипсик)
Актуально: 17.10.2026

## Краткий вердикт
Проект технически зрелый (8.5–9.2/10), документация — на уровне enterprise, основной объём кода готов (~90%). Разделяет проект от релиза не технический долг, а **организационные блокеры** (ключи, staging/VPS, Docker, VAPID-ротация), а также отставание **доказательств живого состояния** (полный живой E2E после этапов 45/46, актуализация снимков `test/Для анализа.txt`, синхронизация инвентаря тестов с реальными заглушками).

## 1. Сильные стороны
- **Производственный стандарт**: «Production ≠ File Created» + Pre-flight Checklist жёстко закрывают класс ошибок «у меня на машине работало».
- **Гейты вместо памяти**: `test-counter-audit.mjs`, `secrets-leak-audit.mjs`, `schema-drift-audit.mjs`, `deploy-rollout-audit.mjs`, `prod-mock-audit.mjs`, `check-security-headers.mjs` исключают молчаливый дрейф конфигов/документов.
- **Security first**: единый гейт `/api/admin` (401/403), только `??` в SQL, запрет пассивных проверок, fail-closed для платных точек.
- **База ошибок**: `docs/AGENTS-pitfalls.md` — уникальный актив с симптомом/причиной/фиксом/правилом.
- **Единый источник истины**: канон `AGENTS.md` + `docs/AGENTS-*.md`, хроника `Что сделано.txt`, архив `docs/agenda-archive.md` защищены `check:docs`.
- **Автоматизация счётчиков**: гейт измеряет фактические числа прогоном, убирает ручной пересчёт.

## 9. Не брать (консенсус)
- SLA/business hours/эскалации, Custom roles, Kanban/Calendar/Wiki/Polls/News — не релевантны dating-проекту.
- Native/WebView E2E (Capacitor) — заблокирован устройством/Android Studio (не притворяться закрытым).
- Quiet hours/DND — отсутствуют по коду, продуктово не требуется.
- Полный CSRF до выноса API на поддомен/первого реального платежа (текущая конфигурация — осознанное решение).
- `npm audit fix --force` для `bull` (понижение до 1.1.3 недопустимо).
- Истинный zero-downtime — зафиксированное ограничение (single-instance, in-memory лимитеры), не «не сделано».
