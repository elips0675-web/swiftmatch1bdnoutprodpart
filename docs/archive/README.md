## Rule

Root-level or archive files are not authoritative unless they are explicitly linked from the active doc set.

Use the following as the source of truth:

- `AGENTS.md`
- `README.md`
- `project-context.md`
- `docs/AGENTS-*.md`
- `docs/product-roadmap.md`
- `Что сделано.txt`
- `Что доделать.txt`
- `Промты.txt`

If a file in this archive is still needed, either link it explicitly from a canonical doc or move it to a more precise folder with a clear reason.
