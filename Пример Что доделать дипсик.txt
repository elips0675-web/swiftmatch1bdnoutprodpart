## Правила работы с этим файлом

- **Бэклог ≠ история.** Новые закрытые пункты — в `Что сделано.txt`; из бэклога закрытый пункт удаляется. В бэклоге — только заголовок-маркер без тела.
- **Числа в шапке** — только прогоном `node scripts/test-counter-audit.mjs` (exit 0). Гейт покрывает 8 файлов: README.md, project-context.md, test/ИНВЕНТАРЬ-ТЕСТОВ.md, test/README.md, test/project-context.md, test/Для анализа.txt, шапки Что сделано.txt / Что доделать.txt.
- **Зеркало test/Что доделать.txt** — побайтово после каждой правки (`npm run check:mirrors --fix`).
- **Кодировка:** править node-скриптами + `cmd /c "node ... > file 2>&1"`, затем читать файл. PowerShell ломает кириллицу.
- **Пункт без `file:line`-цитаты** в план не попадает. Дата проверки обязательна.
- **Объём:** ≤ 1500 строк / 120 КБ.
- **Сначала фикс, потом тест.**
- **Пороги coverage — буфер +2 п.п.** ниже фактического; только вверх.
