📊 Итоговая оценка
Сейчас SwiftMatch: ~7.5/10 (сильный MVP, но не enterprise-grade)
После P0 (1–7): 8/10 — production-ready для корп. интранета
После P1 (8–20): 8.5/10 — полноценный dating-app с монетизацией
После P2 (21–32): 9/10 — enterprise-grade
После бэклога (33–42): 9.5/10 — готов к масштабированию
🎯 Рекомендация: начать с P0
Самый ROI:
IDOR-аудит (2 дня) — критично для dating, сейчас дыры
Race-тесты (2 дня) — лайки/мэтчи/подписки — частый источник багов
Notification preferences (3 дня) — UX-killer feature для dating
Активные сессии (2 дня) — приватность, важно для пользователей
Итого P0+P1: ~30 дней работы, но можно разбить на 4 спринта по 7–8 дней.
Не брать из Service Desk:
Ticket relations / watchers / merge — специфично для helpdesk
SLA/TZ/DST — не актуально для dating
Custom ticket statuses — в dating статусы фиксированные (active/banned/deleted)
Org chart — не нужно для B2C
