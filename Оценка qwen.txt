🔴 Риски и техдолг
Windows-центричность workflow — Laragon, Task Scheduler, .bat, PowerShell. При переезде на Linux VPS нужно адаптировать. Docker Compose есть, но не является основным путём.
mysql_schema.sql деградирован (этап 77/79): schema = 62 таблицы, живая БД = 73. 29 таблиц созданы ТОЛЬКО миграциями. Починено для CI (seed-migrations.mjs), но риск при пересоздании БД с нуля сохраняется.
Single-instance rate-limit (rollback-plan N+2): express-rate-limit и lockout.js — in-memory, НЕ шарятся между процессами. Запрещён pm2 cluster mode и Docker replicas > 1 до миграции на Redis store.
CSRF double-submit — отложено. SameSite=Lax не защищает от same-site атак. Критично только при выносе API на отдельный домен.
Fingerprint refresh (привязка к устройству/IP) — риск сломать мобильный Bearer-flow, делать осторожно после беты.
